# Components — Smartlytics

Tokens: `replica/design/tokens.json` (source) → `tokens.css` (generated by
`python -m smartlytics.ui.theme`) and `.streamlit/config.toml` (Streamlit theme,
this stack's equivalent of a Tailwind mapping). Components use token roles, never
raw hex. Native Streamlit widgets are used wherever they exist, because they come
with keyboard and screen-reader support built in; custom HTML is limited to
read-only display (header, metrics, badges, empty states, step list).

Icons: Material Symbols via Streamlit's `:material/...:` syntax (Apache 2.0).
Font: system sans stack with Inter first (OFL), no licensed fonts.

---

**Page header (hero)**
- variants: with logo, without logo (logo missing or failed to load)
- tokens: gradient hero-from → hero-via → hero-to, title gradient accent → accent-2, radius lg, text xl/800
- states: default; mobile (≤640px: smaller padding and logo)
- a11y: title is a real `<h1>`; logo `alt=""` (decorative, the name is in text); text on hero-to passes 10.1:1
- fixes: B7 — logo is embedded as base64, not a relative `src` Streamlit can't serve
- used on: every page

**Sidebar navigation** (replaces the Hub's 5 buttons)
- built with `st.navigation`, so the active page is highlighted and the URL changes per page
- groups: Data (Upload, Overview), Analyse (Sales, Customers, Charts), Share (Report)
- states: default, active, disabled-looking pages still reachable but show the no-dataset gate
- a11y: native links, keyboard reachable; page titles set per page

**Button**
- variants: primary (one per screen: the main action), secondary, tertiary (link-like)
- sizes: Streamlit default (40px tall)
- states: default, hover, focus-visible (2px focus-ring, offset 2), disabled, loading (wrapped in `st.spinner`, label unchanged)
- tokens: primary bg accent / text on-accent (9.1:1); secondary surface / text; radius md
- a11y: native `<button>`; every button has a unique `key` (fixes B5)
- used on: S01, S02, S04, S05, S07

**File uploader**
- accepts: .csv, .xlsx (fixes "Excel rejected" from F01)
- states: idle, file chosen, reading (spinner), success (toast), error (inline `st.error` with what went wrong and what to do), too large (>50 MB) — Streamlit blocks it with its own message
- helper text: privacy line ("Your file stays in this browser session and is never stored")
- used on: S01

**Demo data button**
- secondary button "Try with sample sales data"; loads the bundled sample
- used on: S01 empty state

**Metric card**
- parts: label (xs, muted, uppercase), value (metric 28/700, tabular figures), optional hint
- states: value, not available ("—" with hint saying why)
- a11y: label and value in reading order, not colour-coded
- used on: S02 (rows, columns, missing %, duplicates), S07 (total revenue, total profit, margin, high-tier share)

**Tier badge**
- variants: High, Medium, Low
- tokens: tier-high / tier-medium / tier-low text and border on surface (all ≥6.2:1)
- rule: never colour alone — always the word, plus ▲ / ● / ▼ glyph, so it works in greyscale and for colour-blind users
- used on: S07 table, report

**Data table**
- `st.dataframe` with column config (number formats, 2 dp for money, % for shares)
- states: filled, empty (empty state component instead of an empty grid), large (virtualised by Streamlit; display capped at 1,000 rows with a note)
- used on: S02, S07, customers, S05 preview

**Select / multiselect / radio**
- native widgets; label always visible; unique `key`
- column pickers are filtered by type (numeric / category / date) and show the type in help text
- empty option list → disabled with a caption explaining why ("No date columns found")
- used on: S02, S04, S07, customers

**Column-mapping form** (new)
- one select per sales field: Revenue (required), Cost, Quantity, Date, Customer, Product
- toggle: "Cost is per unit" (default on when a quantity column is mapped)
- pre-filled by `sales.guess_mapping`; shows a green tick per field that was auto-detected
- states: complete, missing required field (error text under the field, submit disabled), invalid (non-numeric column chosen for revenue: inline error)
- `st.form` so the analysis runs once on submit, not on every change
- used on: S07

**Chart**
- Plotly, themed from tokens (`chart.categorical`, gridline, axis-text), transparent background
- kinds: histogram, bar (aggregated), pie (top 10 + Other), scatter (sampled), correlation heatmap, trend, profit thresholds (Q25/Q75/mean lines, labelled in text not only colour), sales vs profit
- threshold labels: stagger vertically (Q25 top, mean middle, Q75 lower) because the gallery showed Mean and Q75 labels colliding when the values are close; values also repeated in the caption
- states: rendered, not possible (empty state saying which column type is missing), large (sampling note under the chart)
- a11y: every chart has a text title and a one-line caption with the key number; data available as a table toggle
- used on: S04, S07, report

**Alert / toast**
- `st.toast` for confirmations ("Chart added to report"), `st.success/warning/error/info` inline for states that persist
- tokens: success / warning / danger on surface (all ≥6.2:1)
- copy rule: say what happened and what to do next

**Empty state**
- parts: title, one sentence, optional primary action
- variants: no dataset (gate, S06), no charts saved yet (S05), no sales mapping yet (S07), no repeat customers
- used on: S02–S07

**Cleaning step list (audit log)**
- ordered list, each step: message + rows before → after + time
- states: empty ("No cleaning steps yet"), filled
- used on: S02, report

**Download button**
- native `st.download_button`; label states the format ("Download report (HTML)")
- used on: S05, S07 (top performers CSV)
